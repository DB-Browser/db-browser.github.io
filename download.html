How the CAPTCHA gate works

To reduce automated abuse, downloads are unlocked only after a quick CAPTCHA verification. A separate widget script handles verification and server‑side validation via your TDS, then opens a short‑lived download URL in a new tab.

  • Click “Secure download — Portable”.
  • Complete the CAPTCHA in the pop‑up.
  • On success, the download starts automatically.

Verify integrity

Always verify downloads when possible. Compare file size and checksums against the official release notes.

  • Check file properties after download (size, signature if available).
  • Verify SHA‑256 when a checksum is provided upstream.
